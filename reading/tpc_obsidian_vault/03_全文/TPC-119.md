## Abstract

TPC-MVP1 requires its packet architecture to return to the original TPC-15 scalar defect without changing the fixed shift, normalization, support, or provenance. We make that requirement machine-checkable. For $$Q=\lfloor X^{1/2-\delta}\rfloor,\qquad  U=V=\lfloor Q^{1/2}\rfloor,$$ the original packet admits the exact opened form $$B_{h_0,\delta}(X)  =  \sum_{\alpha=(\ell,k,d)\in\mathcal A_X}c_X(\alpha),$$ where $$c_X(\ell,k,d)=  -\Lambda(\ell)\mu(d)r_Q(\ell k+h_0)W(\ell k/X)$$ and $\mathcal A_X$ imposes $\ell>U,\ k>V,\ d\mid k,\ d\le V$.

We encode a complete packet analysis by a canonical leaf matrix $M_X^{\rm can}$, whose columns are native atoms and whose rows are final leaves. If $M_X=M_X^{\rm can}$, if retained and soft leaves partition this matrix, and if $$\mathbf 1^TM_X=\mathbf 1^T,$$ then $$B_{h_0,\delta}(X)  =  \mathbf 1^TM_X^{\rm ret}c_X+  \mathbf 1^TM_X^{\rm soft}c_X$$ exactly. A bound $\mathbf 1^TM_X^{\rm soft}c_X=o(X)$ then gives the required scalar reconnection. The certificate also requires the same $h_0$, one physical normalization, equality of the actual and canonical leaf sets, and recoverable native keys. Merely observing the same scalar sum is weaker: it cannot detect null-pair inflation or equal-valued surrogate atoms.

Applied to the repository series through TPC-118 as audited on 26 July 2026, the result is a precise administrative gap statement. TPC-15 proves the scalar anchor; several later papers prove local identities, provenance interfaces, cover criteria and ledger rules. However, the audited snapshot supplies neither one complete canonical leaf archive from every opened TPC-15 atom through all retained and soft branches nor an alternative exact composite intertwining certificate. In particular, TPC-18 explicitly treats global block cover as an additional hypothesis. Hence the canonical-leaf H8 audit defined here is $$\boxed{\text{not testable from the current artifacts}.}$$ This is a time-stamped gap certificate, not an impossibility theorem, not a claim that this archive format is logically necessary, and not an $\mathrm{L2}$ arithmetic advance.

# Question, scope, and claim boundary

###### ref-5684338d414839ee

For fixed $h_0\ne0$, real $W\in C_c^\infty((0,\infty))$, and fixed $0<\delta<1/2$, TPC-15 proves $$\Delta_{h_0,W}(X)  =  B_{h_0,\delta}(X)  +O_{A,h_0,W,\delta}\bigl(X(\log X)^{-A}\bigr)  \label{eq:anchor}$$ for every fixed $A>0$ [`\citep{WangTPC15}`](../99_%E7%BB%B4%E6%8A%A4/%E5%8F%82%E8%80%83%E6%96%87%E7%8C%AE/TPC-119.md#cite-b0805195de3a7444). Thus $B_{h_0,\delta}(X)=o(X)$ is equivalent, inside that reduction, to the weighted Hardy–Littlewood asymptotic for an admissible even $h_0$.

MVP1 Hypothesis H8 requires all later estimates and reassembly to intertwine with this same scalar packet. It forbids a second global normalization, an omitted branch, a duplicated atom, or a surrogate Gram matrix [`\citep{WangMVP1}`](../99_%E7%BB%B4%E6%8A%A4/%E5%8F%82%E8%80%83%E6%96%87%E7%8C%AE/TPC-119.md#cite-934c301de52ef9a3). The present paper asks only whether that interface has a proof-carrying certificate. It does not estimate the packet.

# The TPC-15 native atom archive

###### ref-6375450ee1b3fa8a

Put $$Q=\lfloor X^{1/2-\delta}\rfloor,\qquad  U=V=\lfloor Q^{1/2}\rfloor,$$ and $$r_Q(n)=\Lambda(n)-  \sum_{q\le Q}\frac{\mu(q)}{\varphi(q)}c_q(n).$$ TPC-15 defines $$B_{h_0,\delta}(X)  =  -\sum_{\substack{\ell>U\\k>V}}  \Lambda(\ell)\beta_V(k)r_Q(\ell k+h_0)W(\ell k/X),  \qquad  \beta_V(k)=\sum_{\substack{d\mid k\\d\le V}}\mu(d).  \label{eq:tpc15-packet}$$

###### ref-658d4f9ff3cb636c

> **Definition: Opened native atoms** Let $\mathcal A_X$ consist of triples $$\alpha=(\ell,k,d)$$ satisfying $$\ell>U,\qquad k>V,\qquad d\mid k,\qquad d\le V,$$ and for which $W(\ell k/X)\ne0$. Define $$c_X(\alpha)  =  -\Lambda(\ell)\mu(d)r_Q(\ell k+h_0)W(\ell k/X).  \label{eq:native-coefficient}$$ The key retains $h_0,Q,U,V,W$ as global packet metadata.

###### ref-381de46bfdcebd4b

###### ref-46a81be2775a6af9

> **Proposition: Exact native-atom anchor** \[prop:native-anchor\] One has the finite identity $$\boxed{  B_{h_0,\delta}(X)  =\sum_{\alpha\in\mathcal A_X}c_X(\alpha).}  \label{eq:opened-anchor}$$

> **Proof** Insert the divisor expansion of $\beta_V(k)$ in [\[eq:tpc15-packet\]](TPC-119.md#ref-6375450ee1b3fa8a) and interchange finite sums.

> **Remark: Why the opened key is necessary** The compressed pair $(\ell,k)$ is sufficient to evaluate the scalar packet, but it is not sufficient to audit later divisor-prefix, content, lcm, and determinant branches. Opening $d$ makes the Möbius sign and every later partition assignment traceable. The opening is exact algebra, not an estimate.

# A proof-carrying reconnection theorem

Let $\mathcal L_X$ be a finite set of final leaf records. A leaf may be a retained packet term or a term assigned to an exactly defined soft remainder. Linear analysis of the native coefficient vector $$c_X=(c_X(\alpha))_{\alpha\in\mathcal A_X}$$ is described by a matrix $$M_X\in\mathbb C^{\mathcal L_X\times\mathcal A_X}.$$ Its synthesized scalar is $\mathbf 1^TM_Xc_X$.

> **Definition: Canonical leaf archive** A canonical leaf archive consists of:
>
> 1.  an expected leaf set $\mathcal L_X^{\rm can}$ generated by the declared partitions, polarizations, frequency bands, content branches, and boundary rules;
>
> 2.  an expected matrix $M_X^{\rm can}$;
>
> 3.  for every nonzero entry, a recoverable native atom, complete branch path, fixed-shift tag, and normalization tag; and
>
> 4.  a disjoint typed partition $$M_X^{\rm can}=M_X^{\rm ret}+M_X^{\rm soft}.$$
>
> An implementation passes the canonical audit only when its leaf set, keys, and matrix equal the declared archive entrywise.

###### ref-ba67628f5b5ace98

###### ref-05e89a7399aa5770

###### ref-9aef48cf18565679

> **Theorem: Sufficient proof-carrying H8 certificate** \[thm:h8\] Assume: $$\begin{aligned}  \mathcal L_X&=\mathcal L_X^{\rm can},  &  M_X&=M_X^{\rm can},  \label{eq:canonical-equality}\\  M_X&=M_X^{\rm ret}+M_X^{\rm soft},  &  \mathbf 1^TM_X&=\mathbf 1^T,  \label{eq:conservation}\end{aligned}$$ and assume every active matrix entry retains the same prescribed $h_0$, the TPC-15 normalization, and a recoverable $\alpha\in\mathcal A_X$. Then $$\boxed{  B_{h_0,\delta}(X)  =  \mathbf 1^TM_X^{\rm ret}c_X+  E_{\rm soft}(X),}  \qquad  E_{\rm soft}(X)=\mathbf 1^TM_X^{\rm soft}c_X.  \label{eq:exact-reconnection}$$ If, in addition, the complete outer soft sum satisfies $$E_{\rm soft}(X)=o(X),$$ then the retained synthesis reconnects to the original packet up to $o(X)$.

> **Proof** By [\[prop:native-anchor\]](TPC-119.md#ref-381de46bfdcebd4b) and [\[eq:conservation\]](TPC-119.md#ref-05e89a7399aa5770), $$B_{h_0,\delta}(X)=\mathbf 1^Tc_X=\mathbf 1^TM_Xc_X.$$ Insert the typed matrix partition in [\[eq:conservation\]](TPC-119.md#ref-05e89a7399aa5770). The metadata hypotheses ensure that this equality concerns the same physical coefficient rather than an averaged shift or rescaled surrogate.

###### ref-aa67a370edfdb28f

> **Remark: Sufficient archive, not a unique proof language** \[rem:not-necessary\] The entrywise equality $M_X=M_X^{\rm can}$ is a strong, machine-checkable sufficient certificate. MVP1 H8 could instead be established by another exact composite symbolic intertwining that proves the same no-omission, no-duplication, fixed-shift, normalization and provenance statements without materializing this particular matrix. Absence of the archive therefore does not prove that H8 is false or that no other proof exists.

###### ref-ed381ac514192f82

> **Corollary: Coefficientwise audit** \[cor:column\] The conservation equation is equivalent to $$\sum_{\lambda\in\mathcal L_X}M_X(\lambda,\alpha)=1  \qquad(\alpha\in\mathcal A_X).$$ Thus deletion, uncompensated duplication, or global rescaling is detected column by column.

> **Remark: Exact identity before estimation** A soft remainder is not permission to discard a branch. The branch first appears in the exact matrix partition; only then may its complete outer scalar be estimated by $o(X)$. Sectorwise or sampled smallness does not fill this slot.

# Why scalar equality is not a provenance certificate

###### ref-3c7a349cfbb18048

> **Proposition: Null-pair and surrogate nonidentifiability** \[prop:null\] Knowledge that $$\mathbf 1^TM_Xc_X=\mathbf 1^Tc_X$$ for one coefficient vector does not imply [\[eq:canonical-equality\]](TPC-119.md#ref-ba67628f5b5ace98) or [\[eq:conservation\]](TPC-119.md#ref-05e89a7399aa5770). This remains true even when the two scalar sums agree exactly.

> **Proof** Append to one atom two noncanonical leaves with multipliers $t$ and $-t$. Their scalar contribution is zero, but the leaf archive has been inflated. Alternatively, if two native atoms happen to have the same numerical coefficient, exchange one for the other. The scalar does not change, while source provenance does. Both operations violate the canonical archive.

Replacing every leaf multiplier by $\gamma_XM_X$ gives a scalar $\gamma_XB_{h_0,\delta}(X)$. A later division by $\gamma_X$ may restore the displayed number, but it introduces a second global normalization and changes every intermediate natural scale. H8 requires the normalization tag to remain the inherited physical one.

An average $$\frac1{|\mathcal H_X|}\sum_{h\in\mathcal H_X}  B_{h,\delta}(X)$$ cannot be tagged $h_0$ merely because $h_0\in\mathcal H_X$. The leaf archive must return the same prescribed shift term by term, unless a separate localization theorem is included with its cost.

> **Remark: Quadratic surrogates** A $TT^*$, Gram, determinant-energy, or Fourier-energy identity is a tool for bounding a linear packet. It is not itself a reconnection map. The final archive must return from the quadratic statistic to the linear leaf coefficients with the exact prefactor and all losses recorded once.

# Minimal completion artifact and claim ledger

A future proof-carrying H8 artifact should contain:

1.  the exact TPC-15 metadata $(X,h_0,\delta,Q,U,V,W)$;

2.  every active opened atom $(\ell,k,d)$ and [\[eq:native-coefficient\]](TPC-119.md#ref-658d4f9ff3cb636c);

3.  the deterministic expected branch paths through every partition, polarization, content, frequency, boundary, and return rule;

4.  the actual final leaf set and exact multipliers;

5.  the retained/soft type of each leaf;

6.  column conservation, unique canonical leaf identifiers, and fixed-shift/normalization checks; and

7.  an analytic citation for the complete outer soft bound.

The accompanying script verifies the finite logic on an exact rational model. It rejects deletion, rescaling, a wrong shift, a second normalization, scalar-preserving null pairs, and equal-valued surrogate provenance. It does not pretend to contain the missing physical archive.
