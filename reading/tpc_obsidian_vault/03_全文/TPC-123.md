## Abstract

TPC-119 gave a sufficient canonical-matrix criterion for reconnecting the later TPC synthesis to the original fixed-shift hard packet, but the audited repository did not contain the complete matrix. We make the missing object local. Every declared partition, polarization, content split, frequency split, boundary rule and return rule is represented by an exact sparse stage matrix $T_j$, and the path-expanded archive records every nonzero edge rather than only its final aggregate. If $$\mathbf 1^TT_j=\mathbf 1^T$$ at every stage and every edge intertwines the native key, prescribed shift and physical normalization, then the composite $M=T_s\cdots T_1$ is coefficientwise conservative and gives the exact TPC-119 reconnection identity. We prove the defect formula $$\mathbf 1_s^TM-\mathbf 1_0^T  =  \sum_{j=1}^s  \bigl(\mathbf 1_j^TT_j-\mathbf 1_{j-1}^T\bigr)  T_{j-1}\cdots T_1,$$ which separates a global defect into typed local defects. Sharp finite examples show why equality on one coefficient vector, a conservative final composite, or an untagged scalar archive does not verify the local path statement. The theorem and exact rational audit are $\mathrm{L0}$; identifying the required TPC fields is an $\mathrm{L1}$ interface. The actual growing branch tables remain absent, so the literal archive is presently $\textsc{not-testable}$. No $\mathrm{L2}$ fixed-shift cancellation, parity advance or prime-pair theorem is claimed.

# Scope and the native entrance

###### ref-7f4c0e3dc5009a9c

Fix a nonzero admissible shift $h_0$, a smooth compactly supported weight $W$, and $0<\delta<1/2$. The TPC-15 hard packet has the opened form $$B_{h_0,\delta}(X)  =  \sum_{\alpha=(\ell,k,d)\in\mathcal A_X}c_X(\alpha),  \qquad  c_X(\alpha)=  -\Lambda(\ell)\mu(d)r_Q(\ell k+h_0)W(\ell k/X),  \label{eq:native}$$ where $\ell>U$, $k>V$, $d\mid k$, and $d\le V$ [`\citep{WangTPC15,WangTPC119}`](../99_%E7%BB%B4%E6%8A%A4/%E5%8F%82%E8%80%83%E6%96%87%E7%8C%AE/TPC-123.md#cite-b0805195de3a7444); [\[WangTPC119\]](../99_%E7%BB%B4%E6%8A%A4/%E5%8F%82%E8%80%83%E6%96%87%E7%8C%AE/TPC-123.md#cite-6287e7598dfbed80). The divisor $d$ is part of the key: compressing $(\ell,k,d)$ to $(\ell,k)$ preserves the scalar in [\[eq:native\]](TPC-123.md#ref-7f4c0e3dc5009a9c) but loses the provenance needed by later content and prefix operations.

###### ref-bfb35208a14925c6

TPC-119 encodes a complete later analysis by a matrix $M_X$ whose columns are the atoms of $\mathcal A_X$ and whose rows are final leaves. Its sufficient conservation condition is $$\mathbf 1^TM_X=\mathbf 1^T.  \label{eq:global-conservation}$$ The remaining difficulty is not linear algebra: it is the absence of one object proving that every intermediate branch has been included with the same $h_0$, normalization and native source. The present paper replaces a monolithic final archive by a composable path archive. It does not estimate any coefficient in [\[eq:native\]](TPC-123.md#ref-7f4c0e3dc5009a9c).

> **Definition: Claim levels** An exact finite identity independent of the arithmetic meaning of the labels is $\mathrm{L0}$. A verified identification of those labels with the literal TPC packet is $\mathrm{L1}$. A growing, coefficient-specific, fixed-$h_0$ arithmetic power saving is $\mathrm{L2}$.

# Typed stages and the path-expanded archive

Let $$R_0=\mathcal A_X,\quad R_1,\ldots,R_s=\mathcal L_X$$ be finite record sets. A record may contain mathematical data in addition to its identifier. For each $j$, let $$T_j:\mathbb C^{R_{j-1}}\longrightarrow\mathbb C^{R_j}$$ be the exact sparse matrix of the $j$-th declared operation. Rows are outgoing records and columns are incoming records. Thus $$M=T_sT_{s-1}\cdots T_1$$ is the aggregate leaf matrix.

> **Definition: Path-expanded archive** A path is a tuple $$p=(r_0,r_1,\ldots,r_s),\qquad r_j\in R_j,$$ such that $T_j(r_j,r_{j-1})\ne0$ for every $j$. Its multiplier is $$m(p)=\prod_{j=1}^sT_j(r_j,r_{j-1}).$$ The path-expanded archive stores the tuple, its multiplier, its native source $r_0$, and the typed metadata on every edge. Paths remain distinct even when they end at the same leaf.

###### ref-2d30064b91532b28

> **Proposition: Path expansion** \[prop:path\] For every $r_s\in R_s$ and $r_0\in R_0$, $$M(r_s,r_0)  =  \sum_{\substack{p:\,p_0=r_0\\p_s=r_s}}m(p).$$

> **Proof** This is the entrywise definition of the product $T_s\cdots T_1$, with all intermediate indices displayed.

The path form is deliberately more redundant than $M$. It records whether an entry arose from the declared branches, whereas a final matrix entry records only their sum. This distinction is essential when opposite errors cancel.

# Local conservation implies exact global reconnection

Write $\mathbf 1_j$ for the all-ones column vector on $R_j$.

###### ref-23e26d83a011d175

> **Definition: Stage conservation** Stage $j$ is coefficientwise conservative when $$\mathbf 1_j^TT_j=\mathbf 1_{j-1}^T.  \label{eq:stage-conservation}$$ Equivalently, the outgoing multipliers above every incoming record sum exactly to one.

###### ref-c07c03e41704aceb

> **Theorem: Local-to-global path conservation** \[thm:local-global\] If [\[eq:stage-conservation\]](TPC-123.md#ref-23e26d83a011d175) holds for every $1\le j\le s$, then $$\boxed{\mathbf 1_s^TM=\mathbf 1_0^T.}$$ Consequently, for every coefficient vector $c\in\mathbb C^{R_0}$, $$\mathbf 1_s^TMc=\mathbf 1_0^Tc.$$ In particular, taking $c=c_X$ from [\[eq:native\]](TPC-123.md#ref-7f4c0e3dc5009a9c) gives exact scalar reconnection to $B_{h_0,\delta}(X)$.

> **Proof** Repeatedly use [\[eq:stage-conservation\]](TPC-123.md#ref-23e26d83a011d175): $$\mathbf 1_s^TT_s\cdots T_1  =  \mathbf 1_{s-1}^TT_{s-1}\cdots T_1  =\cdots=\mathbf 1_0^T.$$ Multiplying by $c$ proves the scalar identity. No positivity, orthogonality or probabilistic interpretation is used.

###### ref-1643d349261b4cc6

> **Corollary: Retained–soft identity** \[cor:retsoft\] Suppose $R_s=R_s^{\rm ret}\sqcup R_s^{\rm soft}$ is a disjoint typed partition. Let $M^{\rm ret}$ and $M^{\rm soft}$ be obtained from $M$ by retaining the corresponding rows and setting the other rows to zero. Under [\[thm:local-global\]](TPC-123.md#ref-c07c03e41704aceb), $$B_{h_0,\delta}(X)  =  \mathbf 1^TM^{\rm ret}c_X+\mathbf 1^TM^{\rm soft}c_X.$$

> **Proof** The row partition gives $M=M^{\rm ret}+M^{\rm soft}$; now apply [\[thm:local-global\]](TPC-123.md#ref-c07c03e41704aceb).

> **Remark: What the theorem does not estimate** The corollary is exact even when both terms are large. To obtain the analytic H8 conclusion, a separate complete theorem must prove $\mathbf 1^TM^{\rm soft}c_X=o(X)$ in the original normalization. Local conservation does not provide that bound.

# The exact defect telescope

Define the stage defect $$d_j^T=\mathbf 1_j^TT_j-\mathbf 1_{j-1}^T.$$ Use the convention $T_0\cdots T_1=I_{R_0}$.

###### ref-e2d9dff3283d6470

###### ref-4d0f04326548e427

> **Theorem: Conservation-defect telescope** \[thm:defect\] For arbitrary compatible stage matrices, $$\boxed{  \mathbf 1_s^TM-\mathbf 1_0^T  =  \sum_{j=1}^s  d_j^TT_{j-1}\cdots T_1.}  \label{eq:defect}$$

> **Proof** Insert and subtract $\mathbf 1_{s-1}^TT_{s-1}\cdots T_1$: $$\mathbf 1_s^TT_s\cdots T_1-\mathbf 1_0^T  =  d_s^TT_{s-1}\cdots T_1  +\mathbf 1_{s-1}^TT_{s-1}\cdots T_1-\mathbf 1_0^T.$$ Iterating proves [\[eq:defect\]](TPC-123.md#ref-4d0f04326548e427).

> **Corollary: First failing conservative stage** If stages $1,\ldots,j-1$ satisfy [\[eq:stage-conservation\]](TPC-123.md#ref-23e26d83a011d175) and $d_j\ne0$, then the path archive contains an exact local failure certificate at stage $j$. This stops the declared locally conservative implementation, even if later matrices happen to cancel its contribution in [\[eq:defect\]](TPC-123.md#ref-4d0f04326548e427).

The last clause matters: global conservation is not the converse of stagewise conservation. A path audit asks whether the declared proof operations themselves are exact partitions, not merely whether their aggregate happens to preserve one scalar.

# Metadata intertwining

Coefficient conservation cannot see a wrong shift or a second normalization. Let $K$ be any discrete metadata set and let $$\kappa_j:R_j\longrightarrow K$$ record one field. For $q\in K$, let $P_{j,q}$ be the coordinate projection onto records with $\kappa_j=q$.

###### ref-f62df65de17824dc

> **Definition: Metadata intertwining** Stage $T_j$ preserves the field $\kappa$ when $$P_{j,q}T_j=T_jP_{j-1,q}  \qquad(q\in K),  \label{eq:metadata}$$ where the second occurrence of $T_j$ is understood with the compatible source and target projections. Entrywise, every nonzero edge has $\kappa_j(r_j)=\kappa_{j-1}(r_{j-1})$.

###### ref-d4a18103c1fda6ed

> **Theorem: Composite metadata preservation** \[thm:metadata\] If [\[eq:metadata\]](TPC-123.md#ref-f62df65de17824dc) holds at every stage, then $$P_{s,q}M=MP_{0,q}  \qquad(q\in K).$$

> **Proof** Move the projection successively through $T_s,\ldots,T_1$.

The fields required by the present route include:

1.  the native atom $(\ell,k,d)$;

2.  the prescribed shift $h_0$ and the single inherited physical normalization;

3.  every partition, polarization, mask, content, boundary and collision tag;

4.  the retained or soft terminal type;

5.  for the TPC-121 interface, the raw atom $t$, determinant bin $\nu(t)$, complex coefficient $u_t$, and the predeclared $X$-indexed bin/good-set rule [`\citep{WangTPC121}`](../99_%E7%BB%B4%E6%8A%A4/%E5%8F%82%E8%80%83%E6%96%87%E7%8C%AE/TPC-123.md#cite-d3e88dbca3ebc492);

6.  for the TPC-122 interface, the canonical fiber order, arithmetic sign $\sigma$, outer weight $w$, and the content remainder allocation [`\citep{WangTPC122}`](../99_%E7%BB%B4%E6%8A%A4/%E5%8F%82%E8%80%83%E6%96%87%E7%8C%AE/TPC-123.md#cite-af7e5d5ca960c85e).

The last two items are data fields, not exponent theorems. Recording them does not prove either $\lambda_D^{\rm cert}$ or $\eta_Z^{\rm cert}$.

# Sharp counterexamples

###### ref-27a5cc15a0b2eb5c

> **Proposition: Scalar coincidence is insufficient** \[prop:scalar\] There are $M$ and $c$ such that $\mathbf 1^TMc=\mathbf 1^Tc$ but $\mathbf 1^TM\ne\mathbf 1^T$.

> **Proof** Take $$M=\begin{pmatrix}2&0\\0&0\end{pmatrix},  \qquad c=\begin{pmatrix}1\\1\end{pmatrix}.$$ Both scalar sums equal $2$, whereas the column-sum row is $(2,0)$.

###### ref-ef9aa38a5903c022

> **Proposition: Local defects may cancel** \[prop:cancel\] There are nonconservative stages whose composite is the identity.

> **Proof** Take $$T_1=\begin{pmatrix}2&0\\0&1/2\end{pmatrix},  \qquad  T_2=\begin{pmatrix}1/2&0\\0&2\end{pmatrix}.$$ Neither stage has column sums $(1,1)$, but $T_2T_1=I$.

###### ref-a58e2498ca18d067

> **Proposition: Conservation does not imply provenance** \[prop:tags\] A permutation matrix can satisfy coefficientwise conservation while exchanging two incompatible metadata tags.

> **Proof** Every permutation matrix has unit column sums. Permute a record tagged $h_0$ with one tagged $h_1\ne h_0$. The coefficient sum is unchanged, but [\[eq:metadata\]](TPC-123.md#ref-f62df65de17824dc) fails for the shift projection.

These examples rule out three common shortcuts: testing only the actual coefficient vector, testing only the final composite, and testing only untagged weights.

# Invocation, data requirements and route verdicts

> **Definition: Paper-specific verdicts** $\textsc{go-interface}$ means that the complete symbolic family of actual stage tables, not merely finitely many numerical samples, passes \[[thm:local-global](TPC-123.md#ref-c07c03e41704aceb),[thm:metadata](TPC-123.md#ref-d4a18103c1fda6ed)\]. $\textsc{stop-declared-route}$ means that an exact defect disproves the declared archive implementation. It is not a global impossibility theorem. $\textsc{not-testable}$ means that a stage table, boundary rule, metadata dictionary or typed comparison object is absent.

They do not, by themselves, provide every $T_j$. Consequently the current repository still lacks the complete growing input needed to run the present audit: $$\boxed{  \operatorname{Archive}_{123}  =  \textsc{not-testable}\ \text{from current artifacts}.}$$ This is a dated administrative statement, not a theorem that no alternative exact H8 proof can exist.

#### Explicit exclusions.

This paper proves no determinant-energy exponent, no zero-mode exponent, no complete physical frame, no fixed-shift localization bound, no signed affine Möbius cancellation, no endpoint below $1/400$, no parity breakthrough, no Hardy–Littlewood asymptotic, and no prime-pair or twin-prime theorem.
