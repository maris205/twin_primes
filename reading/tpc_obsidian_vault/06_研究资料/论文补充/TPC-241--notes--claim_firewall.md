# Claim firewall

The maximum claim is a profilewise unsigned q-collapsed coefficient liminf and its legal finite-window transfer. The following promotions are forbidden:

```text
CLASS_UNIFORM_PROFILE_THRESHOLD = NOT_CLAIMED
PLATEAU_PROFILE_SUBSTITUTION = FORBIDDEN
PHYSICAL_WINDOW_CROSS_TERM_DELETION = FORBIDDEN
SIGNED_C_H_CANCELLATION = NONE
SIGNED_FOUR_PACKET_GATE_B_SCALAR = OPEN
ARITHMETIC_L2 = NONE
STRICT_1_OVER_400 = UNPAID_GLOBAL
TWIN_PRIME_RESULT = NONE
FINITE_FIXTURE_IS_THEOREM_EVIDENCE = FALSE
```

“Sharp up to logarithms” means only that no fixed positive power can be removed from exponent `1/48`; it is not a matching logarithmic asymptotic.
