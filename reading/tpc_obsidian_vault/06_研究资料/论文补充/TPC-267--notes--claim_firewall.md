# Claim firewall

```text
FINITE_OPERATOR = PROVED_EXACT_FINITE
FINITE_PROJECTION_SPLIT = PROVED_EXACT_FINITE
FINITE_RADIUS_INTERVAL = NUMERICALLY_CERTIFIED
FINITE_SIGNED_PHASE = NUMERICALLY_CERTIFIED
ACTUAL_V59_RADIUS_ASYMPTOTIC = OPEN
ACTUAL_V59_PHASE_ASYMPTOTIC = OPEN
FIXED_POWER_CREDIT = 0
ARITHMETIC_ADVANCE = NO
L2 = NONE
FULL_GATE_B = OPEN
TWIN_PRIME_RESULT = NONE
```

The quarter-contraction is a statement about the twelve declared finite tuples and the two declared kernel profiles. It is not a claim that every smooth V59 profile, every (x), or the growing (z=(\log x)\^K) comparator has the same phase sector. No exponent is fitted from the table, and no finite ratio is used as a proof of power saving.
