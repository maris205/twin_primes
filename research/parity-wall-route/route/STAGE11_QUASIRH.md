# 第十一阶段：准 RH 能否改进 MRT 的 8/33？（2026-10-28）

**问题：** OpenAI 2026 年的"准 RH"声称 $\zeta$ 在 $\mathrm{Re}\,s>11/12$ 上没有零点（Lean 验证的是较早的 $7/8$ 版本；$11/12$ 版本尚未形式化，人类专家"大体认为正确"）。它能否把 Matomäki–Radziwiłł–Tao 的"几乎所有 $h\le X^\theta$ 都满足 Hardy–Littlewood"中的 $\theta=8/33$ 往下推？

**一句话答案：不能。** MRT 的 $8/33$ 卡在**临界线上**的矩估计（Type $d_3$、$d_4$ 和），方法的下限 $1/6$ 卡在 $\sigma\approx3/4$ 处的零点密度。$\mathrm{Re}\,s>11/12$ 的无零点区域两者都碰不到。真正能动的杠杆是 Guth–Maynard 2024 的大值估计：它能把下限从 $1/6$ 降到 $2/15$，但同样不动 $8/33$。

**状态标注：** 全部是对已发表证明结构的分析（AI 辅助），不是定理。

---

## 1. MRT 的 $8/33$ 从哪里来（原文 §1.2，arXiv:1707.01315v3）

- 用 Heath-Brown 恒等式把 $\Lambda$ 分解为 Type II、Type $d_1$、$d_2$、$d_3$、$d_4$ 几类和。
- **Type II、$d_1$、$d_2$：** 用 $L^2$ 均值定理和 $L$-函数的四次矩处理。这些已足以恢复 Mikawa / Perelli–Pintz 的 $H\ge X^{1/3+\varepsilon}$。
- **Type $d_3$（越过 $1/3$ 的关键）：** 需要两个估计：
  - Dirichlet 多项式 $D[\mathbf 1_{(X^{1/3},2X^{1/3}]}](\tfrac12+it)$ 在长为 $\sqrt{\lambda X}$ 的典型区间上的四次矩，用 Jutila 的短区间四次矩定理；
  - 在长为 $H$ 的典型区间上的二次矩，借助 Fourier 变换化为指数和，用 Robert–Sargos 的四次矩估计。

  **$8/33$ 正是这一步决定的。**
- **Type $d_4$：** 用 $L^2$ 均值和 van der Corput 指数对 $(1/14,2/7)$，可以做到 $7/30$，比 $8/33$ 更宽松。
- **方法的下限 $1/6$（原文第 4–5 页）：** 对 $h=O(X^{1/6-\varepsilon})$ 的平均 Hardy–Littlewood 会推出"几乎所有长为 $X^{1/6-\varepsilon}$ 的区间里素数定理成立"，而后者目前未知。后者的指数来自 Huxley 的零点密度估计，最坏的位置在 $\sigma=3/4$ 附近。
- **原文脚注 4：** 即使假设 GLH、GRH 或 EH，这个方法也不可能做到 $H$ 慢于 $\log X$。

## 2. 准 RH 为什么帮不上（分析）

| MRT 证明中的输入 | 起作用的区域 | $\mathrm{Re}\,s>11/12$ 的无零点区域是否改进它 |
|---|---|---|
| $L^2$ 均值定理 | 无条件，与零点无关 | 否 |
| $L$-函数的四次矩、Jutila 短区间四次矩 | 临界线 $\sigma=\tfrac12$ | 否：无零点区域不给出临界线上的矩或 Lindelöf 型界 |
| Robert–Sargos、van der Corput 指数和 | 纯指数和，与零点无关 | 否 |
| Huxley 大值估计和零点密度（下限 $1/6$） | 零点密度的最坏位置 $\sigma\approx3/4$ | 否：$N(\sigma,T)=0$ 只对 $\sigma>11/12$ 成立，而那里 Huxley 的界本来就足够好 |

**补充：** 由 $\mathrm{Re}\,s>11/12$ 的无零点区域，只能推出长为 $x^{11/12+\varepsilon}$ 的**所有**区间里素数定理成立，而这比无条件的 Guth–Maynard（$x^{17/30}$）还弱。所以在短区间素数的问题上，准 RH 不提供新信息。

（另外，准 RH 本身尚未经过完整的人工核对。即使它成立，上述结论也不变。）

## 3. 真正的杠杆：Guth–Maynard（分析）

- **Guth–Maynard**（Annals 2025，arXiv:2405.20552）：零点密度 $N(\sigma,T)\ll T^{30(1-\sigma)/13+o(1)}$（Huxley 是 $12/5$）。由此几乎所有长为 $x^{2/15+\varepsilon}$ 的区间里素数定理成立（Huxley 的是 $1/6$）。
- **对 MRT 的意义：** 方法的**下限**可以从 $1/6$ 降到 $2/15$（"小 $\lambda$"部分可以替换）。但实际起约束的是 Type $d_3$ 的 $8/33\approx0.242$，远高于这两个下限。要改进 $8/33$，需要改进**临界线上的短区间矩**（$d_3$），例如更好的 Jutila 型四次矩，或六次矩。
- 我们没有找到"把 Guth–Maynard 用于平均 Hardy–Littlewood"的文献（2026 年 10 月检索）。这可以作为一个具体的研究问题：GM 的大值方法能否直接改进 $d_3$ 估计中的"典型区间"控制？

## 4. 对整体路线图的意义

- 第十阶段：GEH 下的筛法在移位坐标上已经饱和（$1/6$ 密度）。
