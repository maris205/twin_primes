# 第二十一阶段：伸缩平均能否提供奇偶信息？（2026-10-29）

**问题：** 第二十阶段把缺口挪到了"伸缩两点相关的平均非极端性"：
$$R_4=\sum_{p_1,p_2}\Big(\sum_q y(p_1,q)\,y(p_2,q)\Big)^2\ \text{不取极值},\qquad y(p,q)=\lambda(pq+2)\mathbf 1_{\rm rough}(pq+2).$$
本阶段回答两个问题：
1. 对 $(p_1,p_2)$ 求平均，能否像 MRT 对移位 $h$ 求平均那样带来奇偶信息？
2. 是否存在满足筛法公理、却使矩形相关取极值的赝品？

**一句话答案：**
1. **不能。** 伸缩平均不是放宽，而是加强。
   - **严格的部分（命题 21.1）：** 绝对值数据在 $y\mapsto D_uyD_v$（对角符号矩阵）下不变。所以任何绝对值证书，只要能证孪生的非极端性，就必须同时对整条轨道证非极端性，也就是证明割范数 $\|y\|_{\infty\to1}=\max_{u,v}u^\top yv\le(1-\varepsilon)N$（"弱 Type II"）。
   - **MRT 为什么能成：** 加性平均 + 加性移位可以被加性 Fourier 对角化，问题化为单点短区间和，而这是 ① 类已知的结果。伸缩平均是乘法的，移位是加性的，乘法 Fourier 对角化不了加性移位，剩下的是二元扭曲和 $\sum\lambda(pq+2)\chi(pq)(pq)^{-it}$。而 $\chi_0$、$t=0$ 那一项恰好就是孪生和本身。
2. **存在，而且是一整族。** 对每一种符号模式 $u_pv_q$，权 $\omega_{u,v}=1+u_pv_q\lambda(pq+2)$ 都看不见筛法公理（Polymath8b §8 意义下的启发式论证），却使割范数恰好等于 $N$，而 $\sum y$ 可以接近 0。

**数值：** 真实 $\lambda$ 的割范数比值为 $0.258\to0.199\to0.144$（$P=1000\to4000$），按 $k^{-1/2}$ 下降，与随机符号相同。两种赝品都恰好是 1。

**状态标注：**
- 命题 21.1 是严格的初等结论。
- 赝品族在 Polymath8b §8 意义下是启发式的。
- MRT 机制的对比是分析。
- 割范数是数值下界（交替符号最大化，取多次重启中的最好值）。

脚本：`route/stage21_cutnorm.py`；结果见 `stage21_cutnorm_P{1000,2000,4000}_z30.json`。

## 1. MRT 的机制与伸缩平均的对比（分析）

| | MRT（平均 Chowla） | 伸缩平均 |
|---|---|---|
| 平均的参数 | 加性移位 $h\le H$ | 乘法伸缩对 $(p_1,p_2)$ |
| 被平均的相关 | $\lambda(n)\lambda(n+h)$ | $\lambda(p_1q+2)\lambda(p_2q+2)$ |
| 对角化工具 | 加性 Fourier：$\sum_h|\mathrm{corr}(h)|^2=\int|S(\alpha)|^4$ | 乘法 Fourier（Mellin、特征） |
| 化成什么 | **单点**和 $S(\alpha)=\sum\lambda(n)e(\alpha n)$，可用 Davenport 和 MR 短区间定理（① 类） | **二元**扭曲和 $Y(\chi,t)=\sum\lambda(pq+2)\chi(pq)(pq)^{-it}$ |
| 结果 | 已知 | 包含 $Y(\chi_0,0)=\sum y$，也就是孪生和本身，所以是循环的 |

关键在于：MRT 的平均参数和移位属于同一种结构（都是加性的），Fourier 分析能把移位"吸收"掉。孪生的移位 $+2$ 是加性的，伸缩平均却是乘法的，两者混在一起，吸收不掉。这与第十四阶段的观察（移位只在 Mellin 频率 $t\asymp x$ 处可见）是同一个现象。

## 2. 命题 21.1：轨道不变性（严格）

设 $G(\theta,\theta')=\sum_{p,q}y(p,q)\theta_p\theta'_q$，其中 $\theta,\theta'$ 是两个独立的 Haar 环面变量，称 $|G|$ 的分布为 $y$ 的**绝对值数据**；所有矩 $\mathbb E|G|^{2m}$ 和 Schatten 范数 $\|y\|_{S_{2m}}$ 都由它决定。

**(a)** 对任意单位模的 $u,v$，$y$ 与 $D_uyD_v$ 的绝对值数据相同。

**证明：** 作变量替换 $\theta_p\mapsto u_p\theta_p$、$\theta'_q\mapsto v_q\theta'_q$，Haar 测度不变。∎

**(b)** 因此，设 $\Phi$ 是绝对值数据上的任意判据，且由 $\Phi(y)$ 可以推出 $|\sum y|\le(1-\varepsilon)N$。由于 $\Phi(D_uyD_v)=\Phi(y)$，同一判据也推出对所有 $u,v$ 有 $|u^\top yv|\le(1-\varepsilon)N$，即
$$\|y\|_{\infty\to1}\le(1-\varepsilon)N\qquad(\text{弱 Type II}).$$
反过来，弱 Type II 显然推出孪生的非极端性。

**(c)** 矩形相关与割范数的关系：
- $R_4=\|y\|_{S_4}^4\ge\sigma_1^4\ge(\|y\|_{\infty\to1}/k)^4$；
- $R_4\le\sigma_1^2\|y\|_F^2=\sigma_1^2N$，再由 Grothendieck 不等式，$\sigma_1\le K_G\|y\|_{\infty\to1}/k$ 对 $\pm1$ 型的 $y$ 在相差常数的意义下成立。

所以"$R_4$ 非极端"与"弱 Type II"在相差常数和支撑密度的意义下等价。

**结论：** 用绝对值数据能证明的最弱的孪生输入，就是弱 Type II，即**对所有符号模式都非极端**。它比孪生本身（$u=v=1$ 那一个模式）强。

## 3. 赝品族（启发式，Polymath8b §8 意义下）

- 对任意符号 $u,v$，令 $\omega_{u,v}(p,q)=1+u_pv_q\lambda(pq+2)\ge0$。
- 在测度 $\omega_{u,v}$ 下，非零元满足 $u_pv_qy(p,q)=1$，所以 $\|y\|_{\infty\to1}=N$，而 $\sum y$ 可以接近 0（例如随机的 $u=v$）。
- $\omega_{u,v}$ 与原测度的差是一个 $\lambda$ 加权的双线性和。按 Polymath8b §8 的论证，筛法的线性公理看不见这一项。
- $u=v=1$ 时就是 $\delta=0$ 赝品；第十阶段的模 3 赝品在这一类上也给出它。

**所以问题 2 的答案是：** 存在满足筛法公理、又使矩形相关取极值的赝品，而且有一整族，与 $\sum y$ 的取值无关。平均并没有排除它们。

## 5. 对路线图的意义

- **伸缩平均这条路：✗。** 它不是放宽，而是等价于弱 Type II，比孪生本身更强；赝品族也挡住了它。
- **绝对值路线的最弱目标被精确确定为弱 Type II**：对所有 $\pm1$ 系数 $a,b$，有 $|\sum a_pb_q\lambda(pq+2)\mathbf 1_{\rm rough}|\le(1-\varepsilon)N$。
  - 命题 7.8：绝对值方法给不出 $o(N)$。
  - 命题 21.1：绝对值方法即使只想要非极端性，也必须对所有符号模式同时成立。
- **非绝对值路线的最弱目标仍是孪生和本身**（$\delta$ 非极端）。
- **为什么筛法做不到：** 筛法的上界常数恰好卡在 2，也就是赝品让奇类加倍的那个数。要证明奇类不能加倍，就需要上界常数 $<2$，这正是奇偶障碍的经典形式。

**判决：✗（伸缩平均无效）；◎（绝对值路线的最弱目标被精确定为弱 Type II）。**
