# 第六阶段 A：三点相干与移位比较（2026-10-28）

**目标：**
- 把定理 C 推广到三点模式 $(n,n+2,n+6)$；
- 把 Polymath8b 的"GEH ⟹ $H_1\le6$"翻译成 $\delta(2)$、$\delta(4)$、$\delta(6)$ 的语言；
- 证明 GEH + SC ⟹ 孪生素数。

**状态标注：**
- A1 是严格的（与定理 C 同一证明）；
- A3、A4 以 Polymath8b 的定理为黑箱，严格；
- A2 和 §5 的翻译问题是分析；
- §6 是数值。

**一句话结论：**
- 三点相干**超出 GEH**。GEH 只给出三个**成对**的相干，各有自己的参数 $\delta(h)$。
- Polymath8b 的结论翻译过来是一个"**加权析取**"：三个成对量（在 Maynard–Tao 权下）不能同时为 0。
- 由此得到 **GEH + SC$_\nu$ ⟹ TPC**。证明一行，但它把"缺的那块砖"精确地定位为**一个比较不等式**；Polymath 自己指出，正是这一步被奇偶性挡住。

---

## 1. GEH 对三点模式能给什么（A2，分析）

- **定理 C 的证明用了什么：** 它把 Bombieri 定理用在形如 $a_m=\mathbf 1[m+2\in R_{r'}]$ 的序列上，只对**另一个分量**有一个粗糙条件。这类序列在算术级数中的分布由 GEH 保证（引理 4.5、B.1），因为 GEH 正是关于单个卷积 $\alpha*\beta$ 的命题。
- **三点相干需要什么：** 要把两个分量同时联系起来，就要用 $a_m=\mathbf 1[m+2\in R_{s_2}]\,\mathbf 1[m+6\in R_{s_3}]$。这是"一对粗糙数"的示性函数，它在级数中的分布是**孪生型**的分布命题（相当于"粗糙对的 EH"），**不在 GEH 之内**。
- **H3 已经给出的证据：** 在 H3 的线性规划模型中（所有子模式的单边结构加正性），三点模式下 $\delta_{\rm twin}$ 可以取 $[0,2]$ 中任何值，并且有显式见证：孪生对取极端赝品，其余分量独立延拓。所以**仅凭筛法信息**，三个成对参数之间不存在相干关系。
- **结论：** 在 GEH 下，"把 $\delta(2)$ 和 $\delta(4)$、$\delta(6)$ 绑在一起"的三点相干定理**不可得**。若另加一个"成对分布假设" GEH$_2$，三点相干预期可以按定理 C 的方式证明。这一点待写。

## 2. A1：成对相干对每个移位都成立（严格）

**命题 A1.** 设 EH、GEH 成立，$h\in\{2,4,6\}$。令
$$\mathfrak S(h)=2\Pi_2\prod_{p\mid h,\,p>2}\frac{p-1}{p-2}\qquad(\mathfrak S(2)=\mathfrak S(4)=2\Pi_2,\ \mathfrak S(6)=4\Pi_2),$$
用间隙为 $h$ 的素数对定义 $\delta_x(h)$，并把模型中的 $2\Pi_2$ 换成 $\mathfrak S(h)$。则对所有 $s,r'\le r_{\max}$，
$$u_h(s,r')=(\delta_x(h)-1)(-1)^{s+r'}+o(1).$$

**证明：** 与定理 C 逐字相同，只有引理 3.4 中的局部因子要改。对奇素数 $p\mid h$，$p\mid n$ 推出 $p\mid n+h$。当 $p<z$ 时序列在这些 $n$ 上为 0，所以 $g(p)=0$（和 $p=2$ 的处理一样），$G(1)$ 因此变为 $\mathfrak S(h)$。其余步骤（引理 4.5、定理 4.1、两侧合并）都不涉及 $h$ 的具体值。∎

**推论：** 推论 4.7 对每个 $h$ 也成立。但三个参数 $\delta(2)$、$\delta(4)$、$\delta(6)$ **彼此独立**（§1）。

## 3. A3：Polymath8b 在奇偶语言中的形式（严格，以 Polymath8b 为黑箱）

**Polymath8b 的结论**（GEH，$k=3$，容许元组 $\mathcal H=\{0,2,6\}$，带 $\varepsilon$-扩大支撑的 Maynard–Tao 筛）：存在非负权 $\nu(n)=\bigl(\sum_{d_i\mid n+h_i}\lambda_{d_1,d_2,d_3}\bigr)^2$ 和固定的 $c>0$，使得当 $N$ 充分大时
$$\sum_{i=1}^3\sum_{n\sim N}\nu(n)\mathbf 1_{\PP}(n+h_i)\ \ge\ (1+c)\sum_{n\sim N}\nu(n).$$
（这就是他们证明 $H_1\le6$ 的判据。定理编号，我们记得是 Theorem 1.4，待与正式版本核对。）

**逐点不等式：** 对 $\{0,1\}$ 值的 $\epsilon_1,\epsilon_2,\epsilon_3$，有
$$\sum_i\epsilon_i-1\le\sum_{i<j}\epsilon_i\epsilon_j .$$
（0、1、2、3 个素数时，左边分别是 $-1,0,1,2$，右边分别是 $0,0,1,3$。）

**命题 A3.** 记 $S_1=\sum\nu(n)$，以及
$$D_\nu(2)=\frac{\sum\nu(n)\mathbf 1_{\PP}(n)\mathbf 1_{\PP}(n+2)}{S_1},\quad D_\nu(4)=\frac{\sum\nu(n)\mathbf 1_{\PP}(n+2)\mathbf 1_{\PP}(n+6)}{S_1},\quad D_\nu(6)=\frac{\sum\nu(n)\mathbf 1_{\PP}(n)\mathbf 1_{\PP}(n+6)}{S_1}.$$
则在 GEH 下，对所有充分大的 $N$，
$$D_\nu(2)+D_\nu(4)+D_\nu(6)\ \ge\ c .$$

**证明：** 把逐点不等式乘以 $\nu(n)\ge0$ 并求和，再用 Polymath8b 的判据。∎

**奇偶语言中的读法：**
- $D_\nu(h)$ 是**在 Maynard–Tao 权下**、间隙为 $h$ 的素数对的质量，而这个权依赖第三个分量的因子。
- A3 说的是：三个"加权成对奇偶参数"**不能同时**取赝品端点。
- 这是一个**析取**命题，不能拆成任何一个单独的 $\delta(h)>0$。

## 4. A4：GEH + SC$_\nu$ ⟹ 孪生素数（严格）

**SC$_\nu$（加权移位比较）：** 存在 $\kappa>0$，使得对无穷多个 $N$，在 A3 的权 $\nu=\nu_N$ 下有
$$D_\nu(2)\ \ge\ \kappa\,\bigl(D_\nu(4)+D_\nu(6)\bigr).$$

**定理 A4.** GEH 与 SC$_\nu$ 推出孪生素数有无穷多对。

**证明：** 由 A3，$(1+1/\kappa)D_\nu(2)\ge D_\nu(2)+D_\nu(4)+D_\nu(6)\ge c$，所以 $D_\nu(2)\ge\kappa c/(1+\kappa)>0$。因此存在 $n\sim N$ 使 $\nu(n)>0$，并且 $n$、$n+2$ 都是素数。对无穷多个 $N$ 成立。∎

**一个与权无关、但更强的版本 SC$_{\rm univ}$：** 对**所有** $\{0,2,6\}$ 上的 Selberg 型非负权（支撑在 $d_i\le x^{1/2}$ 一类的范围），都有 $D_\nu(2)\ge\kappa(D_\nu(4)+D_\nu(6))$。它蕴含 SC$_\nu$。

## 5. 为什么不能直接写成 $\delta(2)\ge\kappa\max(\delta(4),\delta(6))$（分析）

- **翻译需要什么：** A3 中的量带着依赖第三个分量的权 $\nu$。要把 $D_\nu(h)$ 写成定理 C 意义下的 $\delta(h)$ 乘以显式因子，就需要三点相干，而 §1 说明它超出 GEH。
- 所以**纯成对**的比较假设 SC$_\delta$（"$\delta(2)\ge\kappa\max(\delta(4),\delta(6))$"）与 GEH 合在一起**推不出** TPC。中间还缺一条"加权到不加权"的桥。
- **两条可能的出路：**
  1. 加上 GEH$_2$（成对分布假设）。预期可以证明三点相干，从而 GEH + GEH$_2$ + SC$_\delta$ ⟹ TPC，全部用 $\delta$ 的语言。这一步待写。
  2. 接受 SC$_\nu$ 的加权形式。它就是 Polymath 框架里自然出现的比较量。
- **SC 为什么是必需的：** Polymath8b 指出，奇偶问题使他们的方法无法把 $H_1\le6$ 改进到 $H_1\le4$ 或 $2$（具体章节待核对）。在我们的语言里，这就是说：存在与全部筛法信息相容、但 $D_\nu(2)=0$ 的赝品世界。所以 SC 恰好是被奇偶性挡住的那一步，**不能**用筛法得到。

## 6. 数值（[triple_pairs.py](triple_pairs.py)，$X=10^8$，$n\in(X/10,X]$）

| 量 | 值 |
|---|---|
| 不加条件的素数对个数，间隙 2 / 4 / 6 | 381332 / 381636 / 762701（6 比 2 为 2.000，与 $\mathfrak S(6)/\mathfrak S(2)=2$ 一致） |
| 三元组内、第三个分量 $X^{0.1}$-粗糙时的 $C_2:C_4:C_6$ | 1 : 0.9998 : 1.0007 |
| 同上，$\eta=0.2$ | 1 : 0.9989 : 0.9979 |
| 同上，$\eta=0.3$ | 1 : 0.9999 : 0.9986 |
| 粗糙三元组中素数个数的期望（$\eta=0.1/0.2/0.3$） | 0.64 / 1.14 / 1.69 |

**解读：**
- 在容许三元组内部，三种素数对的频率相同（3-进因子在三个位置上一样），所以真实世界里 SC 成立，$\kappa\approx\frac12$。
- 当 $\eta\ge0.2$ 时，粗糙三元组中素数个数的期望已经大于 1，鸽笼原理本可直接用。但"粗糙三元组的个数"本身对奇偶敏感（推论 4.7），筛法算不出来。这正是 Maynard–Tao 要用光滑权、而不能用粗糙示性函数的原因。

## 7. 结论

1. **A1（严格）：** 定理 C 对移位 $h=2,4,6$ 各自成立，三个参数互相独立。
2. **A2（分析）：** 三点相干需要成对的分布假设 GEH$_2$，超出 GEH。
3. **A3（严格，以 Polymath8b 为黑箱）：** GEH ⟹ 在 Maynard–Tao 权下，三种素数对的质量之和 $\ge c$，即加权析取。
4. **A4（严格）：** GEH + SC$_\nu$ ⟹ TPC。SC$_\nu$ 是一个**比较**不等式，在真实世界中成立（$\kappa\approx\frac12$），并且正是 Polymath 所说的奇偶障碍所在。
5. **对路线图的意义：** 候选 A 完成了。条件通路从"GEH + PND$_{\log}$"缩短到"GEH + 一个比较不等式"，离已知定理（Polymath8b）只差这一个不等式。它**没有**绕开奇偶墙：SC$_\nu$ 本身对奇偶敏感。
6. **可选的后续：**
   - A5：在 GEH$_2$ 下证明三点相干，把 SC 写成纯 $\delta$ 语言；
   - 核对 Polymath8b 的定理编号和奇偶讨论的章节，再把 A1、A3、A4 写入论文（v1.0）。
