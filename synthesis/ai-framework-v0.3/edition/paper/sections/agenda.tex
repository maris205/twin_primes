The next stage should treat mathematical progress, resource engineering, and AI performance as separate outcomes. The following agenda is prospective: no experiment, new theorem, or route reopening is reported by stating it. The current mathematical position is Island 2, toward map Bridge A and analytic Gate B, with both analytic gates unresolved.

\subsection{Mathematical track: source-exact continuations}
For Islands 2--4 and Bridge A, priorities include a coefficient-sensitive input for the literal signed interior and a two-sided attachment with every coefficient and residual cost paid. A continuation intended to satisfy Gate B must ultimately yield a full-scalar saving $\delta>1/400$ in the stated physical regime. Intermediate results should state precisely which attachment or loss obligation they resolve. For the critical-array route specifically, the additional loss must satisfy $\ell<19/2400$, with $\delta=1/96-\ell$. The already proved boundary contribution only permits the full saving $\min(\delta_{\rm int},11/64)$ after an interior bound is supplied. It does not provide that bound.

A candidate should be written first as an attachment statement: actual expression, admissible supports, exact coefficients and masks, common parameter ranges, normalization, and total loss. The structural interfaces on Islands 3--4 do not themselves construct the production attachment. Gate A also remains separate, and the conditional output for $S_x^{\rm phys}$ in Section~\ref{sec:bridges} is not the von Mangoldt-weighted pair sum $S_2(x)$. This paper does not reconstruct the complete upstream implication to the twin-prime conjecture. The current stop condition excludes generic norm repairs without an identified new source-exact input; a plan or diagnostic alone is not such an input.

For Island 5 and Bridge B, one concrete target is the joint cylinder bound in Proposition~\ref{prop:seed}, with a fixed positive margin on the same unbounded sequence. Any proposed cylinder scale must control both $\Omega_N$ and $\sqrt{q_N}V_N$; small point-evaluation cost alone is insufficient, while the finest cylinder eliminates oscillation at an unaffordable generic cost. The criterion is only one sufficient route. Alternative distinguished-orbit arguments remain possible if they preserve exact prime-pair encoding. Island 7 may assist through an exact event, time, and seed correspondence, but a geometric representation is not a replacement for that arithmetic return.

\subsection{Resource track: selective formalization and maintainable records}
The first engineering step is to standardize claim and task records on the selected source families, then test whether updates preserve locators, hypotheses, and evidence categories. A small formalization pilot could target self-contained finite identities or the cylinder averaging argument before attempting larger analytic dependencies. Each pilot would need an explicit formal statement, assumptions, a checked correspondence with the original source, and a kernel-checked proof. Library availability and formalization effort must be assessed before selecting the final pilot. Nothing in the current hash, rendering, or editorial checks supplies this formal guarantee.

\subsection{Evaluation track: does the framework help an AI assistant?}
The primary hypothesis is that a source-derived scope-record package reduces unsupported claim promotion on bounded source-grounded tasks. This is a hypothesis, not an observed benefit. Candidate tasks include source localization, hypothesis-preserving reconstruction, evidence-category classification, and detection of deliberately introduced scope errors in separate test copies. Examples include weakening a strict inequality, omitting a residual, confusing map Bridge B with analytic Gate B, and replacing a prescribed seed by an almost-everywhere quantifier.

Compare three access conditions using the same model version and matched task, token, and tool allowances: unstructured source access, ordinary retrieval, and retrieval with scope records and the bounded output contract. All conditions should access the same underlying source corpus; actual usage, retrieval settings, review passes, and abstention policy must be reported. A fixed-review ablation should remove the records. This tests the complete record intervention, including its source-derived explanatory guidance, not formatting alone. Isolating structure itself would require a further control with the same record facts and wording in unstructured form.

Reference answers require human mathematical adjudication on selected tasks; the archive is not already a verified benchmark. Construct admissible source-derived records without access to test questions or rubrics, and freeze them before evaluation. Exclude test-specific answers, planted-error locations, and adjudication rationales from every accessible index. The disclosed K02/K13/K14 cases are development illustrations, not evidence of undisclosed-task generalization. Split by underlying source family and audit shared-source duplication; card and manuscript numbers alone do not prevent leakage. A later temporal split remains prospective.

Primary outcomes should pair unsupported-claim frequency with correct-answer coverage and hypothesis retention, so that universal abstention cannot count as success. Secondary measures can include correct source spans, appropriate abstention, and human correction effort. Blind adjudicators to the access condition, retain disagreements, and report paired task-level comparisons with uncertainty clustered by source family; repeated runs should not be counted as independent mathematical tasks.

\subsection{Sequence and decision points}
First freeze a small adjudicated task set and establish source and leakage checks. Next run a limited matched-budget pilot and inspect both task quality and failure categories. Only after those checks should a larger evaluation or selective formalization proceed under a separately approved resource budget. The companion experiment plan records these stages as not run, with explicit inputs, metrics, and stop conditions. No calendar, compute allocation, statistical power, or successful outcome is inferred from the existence of this agenda.
