This synthesis selects sources from 420 TPC directories. That inventory counts neither independent contributions nor manually verified full texts.

The companion catalog records original names, hashes, and provisional island labels. The core matrix gives source paths, line ranges, SHA-256 hashes, and claim boundaries. Its JSON paths are repository-relative; the readable revision rebases links without changing claims. Hashes establish fidelity, not mathematical correctness. Status files and the map do not replace proofs.

Section~\ref{sec:structure} uses original TeX manuscripts. The analytic core uses the unnumbered proof packages of 9 September 2026; Section~\ref{sec:dynamics} uses the original moving-target, seed, and physical-intertwining sources. Reorganization makes no first-discovery claim.

The wiki's fourteen cards distinguish definitions, estimates, obstructions, and conditional transfers. The concordance links them to revised sections and original source IDs; this navigation supplies no independent proof evidence.
